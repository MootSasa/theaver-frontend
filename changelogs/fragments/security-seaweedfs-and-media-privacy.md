### ru
- **Приватность фотографий, баннеров и контактов:** доступ к медиафайлам и изображениям профиля теперь проверяется для каждой учётной записи — персональные аватары контактов и предложенные фотографии доступны только уполномоченным участникам и не открываются по прямой ссылке без авторизации.
- **Безопасный вход:** полностью удалены устаревшая кнопка тестового входа и сохранённые данные офлайн-режима.

### en
- **Media and profile privacy:** access to chat attachments, profile avatars, banners, wallpapers, and custom contact photos is now verified per account so private media cannot be opened anonymously via direct links.
- **Cleaner authentication:** removed the legacy offline test sign-in option and automatically clear any leftover offline test profile data on startup.
